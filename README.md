# 🚀 Studently — All-in-One Student AI Toolbox

**Studently** is a modern, premium All-in-One Student Ecosystem designed to help students manage study goals, pocket money, official document formatting, career roadmaps, and scholarship opportunities.

## 🌟 Key Features & Mini-Tools

- 🏠 **Personalized Student Dashboard**:
  - Target Career Goal tracking.
  - Interactive Study Streak counter (`+1 Check-in`).
  - Real-time Savings and Skills Progress meters.
  - Seamless Dark Mode & Light Mode toggle with branding customization.

- 🎓 **1. Course & College Finder**:
  - Filter by Plus Two %, Stream, Budget (₹20k–₹200k/yr), and Location.
  - Instant cut-off match scores, fee breakdowns, and career outcomes.

- 💰 **2. Student Money & Expense Tracker**:
  - Daily expense logger with categories (Food, Books, Transport, Subscriptions).
  - Monthly budget limit progress bar & savings deposit tracker.
  - Interactive Recharts category breakdown pie chart.

- 📚 **3. AI Study Assistant**:
  - **Notes Summarizer**: Auto-generate executive bullet points from lecture notes.
  - **Quiz Generator**: Practice MCQs with instant scoring and explanations.
  - **Flashcard Deck**: 3D flip card memory revision deck.
  - **Pomodoro Timer**: 25-min study & 5-min break timer with sound alerts.

- 🎓 **4. Scholarship Finder**:
  - Directory of Central NSP, INSPIRE, AICTE Pragati, Reliance Foundation, and State Merit scholarships.

- 📄 **5. Passport Photo & Document Tools**:
  - **Passport Photo Maker**: HTML5 Canvas cropper for 35x45mm official size, studio background colors (White, Blue, Grey), brightness & contrast sliders.
  - Export single PNG photo or 4x6 printable grid sheet (8 photos).

- 🧑‍💻 **6. Interactive Career Roadmap**:
  - Step-by-step career node trees (BCA/CS to Full Stack Developer, Data Science & AI).
  - Click nodes to complete skills and update dashboard statistics in real time.

- 🤖 **7. AI Chat Assistant**:
  - 24/7 student-tuned AI assistant for code debugging, essay outlines, and exam prep.

- ✍️ **8. Social Caption & Hashtag Generator**:
  - Generate creative Instagram, LinkedIn, and Twitter study post captions.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/naswn/Studently.git
   cd Studently/client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local dev server:
   ```bash
   npm run dev
   ```

4. Open browser at `http://localhost:3000`
